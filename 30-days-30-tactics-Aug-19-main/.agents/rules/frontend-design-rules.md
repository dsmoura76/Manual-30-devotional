# Premium Frontend Design System Directive
- DO NOT generate generic, cookie-cutter, or component-library default layouts.
- Ban the use of default bright Tailwind colors. Utilize deeply saturated zinc neutrals, dark obsidian layers, and sophisticated slate values.
- Treat every layout like an award-winning digital design agency studio piece (e.g., Apple, Linear, or Stripe aesthetic). 
- Prioritize high-end modern typography styling: thin elegant tracking, large font-serif elements for editorial context, and heavy drop-shadow masks.
- Every interactive element (buttons, cards, links) MUST possess physical-feeling CSS states (e.g., cubic-bezier transitions, micro-scaling on click, and elegant active overlays).
- Avoid template cards. Lean heavily into asymmetrical layouts, immersive backgrounds, and border-fading canvas aesthetics.

# Creative Director Override: Anti-Cliche / High-Taste Design Rules
- **Typography Subversion:** Never use centered inter-sans pairings. Force massive editorial layouts, extreme letter-spacing offsets (`tracking-tighter` or `tracking-[0.2em]`), and mixed serif/mono fonts.
- **Asymmetrical Compositions:** Do not use predictable 2-column or 3-column grids. Force overlapping layout layers, unexpected absolute-positioned graphic items, and negative white space.
- **Micro-Textures & Atmosphere:** Inject luxury web details. Use glassmorphism (`backdrop-blur`), subtle noise texture overlays, and soft animated mesh gradients rather than flat backgrounds.
- **Sensory Motion Transitions:** Every scroll action must have a deliberate physical inertia feel. Use customized `cubic-bezier` timing curves (e.g., `cubic-bezier(0.16, 1, 0.3, 1)`) for all Framer Motion components instead of default generic spring physics.
- **Banned Patterns:** Instantly reject standard shadcn card templates, default pricing grids, rounded button bubbles, and generic hero structures. Treat the interface like a digital exhibition piece.
